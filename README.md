# e-plantShopping

## Project Overview
**e-plantShopping** (Paradise Nursery) is an interactive, modern e-commerce web application built using React. The application provides an intuitive shopping experience for plant enthusiasts, offering a variety of indoor, air-purifying, and aromatic plants to help users create greener and healthier spaces.

## Key Features
- **Landing Page:** Welcomes users with an introduction to Paradise Nursery and a quick "Get Started" call-to-action.
- **Product Catalog:** Browse a diverse list of plants complete with images, categories, descriptions, and pricing.
- **Interactive Shopping Cart:** Seamlessly add items to your cart, update quantities, view itemized totals, and proceed to checkout.
- **Responsive Design:** Optimized layout for smooth navigation across desktop and mobile devices.

## Tech Stack
- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Styling:** CSS3
- **Version Control:** Git & GitHub
